# Teapot Surfer

**Teapot Surfer** is a new, simple, minimalist browser designed for productivity. Built using **Electron.js** and **React.js**, it aims to reimagine the browser experience with a focus on clarity and efficiency.

## Status

This project is in early development. Teapot Surfer is currently a work in progress—core browser features and user guides are coming soon.

## Roadmap

- Core browsing functionality
- Clean, distraction-free UI
- Expansion of production-focused tools

## Contributing

A detailed guide for contributors will be released soon. Stay tuned for updates on how to get involved and help shape Teapot Surfer!

***

*This project is under active development. Feedback and ideas are welcome as we build Teapot Surfer together!*
